# System tray icon theme

The **System tray icon theme** preference changes the tray icon independently of the application
theme. **Follow system appearance** is the default; **Light** and **Dark** force the matching icon
tone. On macOS, UniGetUI uses a template icon that macOS tints, so this preference is not shown.

## Manual verification

1. Open **Settings → User interface preferences**.
2. Change the application theme and confirm the tray icon setting stays unchanged.
3. Select **Light** and **Dark** in turn and confirm the tray icon tone changes without changing
   the application theme.
4. Select **Follow system appearance**, switch the system/taskbar appearance, and confirm the tray
   icon follows it.
